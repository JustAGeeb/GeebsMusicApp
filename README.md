# Geeb's Music App

Download songs and videos from YouTube and TikTok, then listen to and watch
them, in one small Windows app.

## Download

Get the latest installer from
**[Releases](https://github.com/JustAGeeb/GeebsMusicApp/releases/latest)** and
run the `.msi`.

Already installed? The app keeps itself up to date: it offers new versions
automatically, or use **App → Check for updates…**.
